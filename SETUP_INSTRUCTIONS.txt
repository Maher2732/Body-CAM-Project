1. Create a Python virtual environment

Windows:
python -m venv .venv
.venv\Scripts\activate

macOS / Linux:
python3 -m venv .venv
source .venv/bin/activate


2. Install the required Python libraries

Make sure the virtual environment from Step 1 is active first (you should see
(.venv) at the start of your terminal prompt), or the libraries will be
installed into a different Python.

This installs pandas, yt-dlp, scipy, scikit-learn and the other libraries the
project needs.

Windows:
pip install -r requirements.txt

macOS / Linux:
pip3 install -r requirements.txt


3. Install FFmpeg

Windows:
winget install Gyan.FFmpeg

Then find the FFmpeg path:
where.exe ffmpeg

macOS:
brew install ffmpeg

Then find the FFmpeg path:
which ffmpeg


3b. Install Deno (needed by yt-dlp for YouTube downloads)

macOS:
brew install deno

Windows:
winget install DenoLand.Deno


4. Create your config file

Copy config.example.json and rename the copy to config.json.

Windows:
Copy-Item config.example.json config.json

macOS / Linux:
cp config.example.json config.json

Then open config.json and replace PATH_TO_FFMPEG_EXE with the FFmpeg path from Step 3.

Example config.json:

{
  "excel_path": "data/labdata_1.xlsx",
  "video_folder": "data/videos",
  "clip_folder": "data/clips",
  "ffmpeg_exe": "PATH_TO_FFMPEG_EXE",
  "browser": "firefox",
  "cleaned_dataset": "data/cleaned_annotations.xlsx"
}

On Windows, use forward slashes or double backslashes in the FFmpeg path, e.g.
"C:/ffmpeg/bin/ffmpeg.exe" or "C:\\ffmpeg\\bin\\ffmpeg.exe"


5. Firefox / YouTube setup

The downloader uses your browser's cookies. The browser is set by the "browser"
key in config.json (default: firefox).

Make sure:
- That browser is installed.
- You are logged into YouTube in that browser.
- If the downloader cannot access cookies, close the browser and try again.


6. Run the project

Windows:
.venv\Scripts\activate
python src/main.py

macOS / Linux:
source .venv/bin/activate
python3 src/main.py

main.py runs the whole project in order:
1. Downloads videos to data/videos
2. Cuts clips into data/clips
3. Saves the cleaned dataset to data/cleaned_annotations.xlsx
4. Prints a summary of the data (risk levels, missing values, rows per video,
   correlations and average risk by category)
5. Prints the majority-class baseline for the low / medium / high risk groups

To skip the YouTube download and use the videos you already have:

python src/main.py --skip-download

Close data/cleaned_annotations.xlsx in Excel before running, or saving it fails.


7. Gemini API key (only for the LLM experiments in src/llm/)

1. Create a key at https://aistudio.google.com/apikey
2. Copy .env.example to .env (in the project root) and paste your key after
   GEMINI_API_KEY=
3. Never commit .env or share the key. .env is git-ignored.
